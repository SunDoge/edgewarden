# Web localization

English is the default UI language. Simplified Chinese remains available through
the language switcher. The saved preference takes precedence; switching does not
reload the page or discard an unlocked vault or form draft.
The preference is local to the browser, not an account or server setting.

The client-only (`ssr=false`) adapter in `src/lib/i18n/locale.svelte.ts` supplies
a reactive Paraglide getter. If storage is blocked, switching still works for
the current session but cannot be remembered. Revisit this adapter before adding
SSR or locale-prefixed routing; never share mutable locale state across server
requests.

## Adding copy

- Add matching message keys to `apps/web/messages/en.json` and `zh-CN.json`.
  Use concise English and consistent Bitwarden terminology: master password,
  two-step login, vault, organization, collection, passkey, and Send.
- Regenerate message types with `pnpm --filter @edgewarden/web run i18n:compile`.
  Never edit or commit generated `src/lib/paraglide` files. Keep the CLI and
  Vite compiler locale strategies identical.
- Call Paraglide messages in components and user-facing service errors. Do not
  hard-code either language in new UI. Translate labels, accessible names,
  placeholders, page titles, notifications, confirmations, and empty/error states.
- Translate whole sentences with parameters. Do not concatenate translated
  fragments: other languages may need a different word order. Prefer named
  parameters for new messages and neutral count labels or proper plural variants.
- Keep message calls reactive. For label arrays in Svelte, use `$derived`, not a
  module-level array of already translated strings. Translate at display time
  rather than caching the result as domain data.
- Use the locale-aware helpers in `src/lib/i18n/format.ts` for display dates.
  Storage, protocol timestamps, IDs, and export field names must not be localized.
- Never translate user-provided names, passwords, notes, URLs, or ciphertext.
  Public demo fixture content is sample data, not UI copy; changing catalogs does
  not rewrite an existing demo database.
- The official server's `src/Core/Resources/SharedResources.en.resx` is a useful
  terminology reference, not a complete web-client catalog. Edgewarden-specific
  operational copy is maintained here. Do not import server workflows that this
  project does not implement.

## Verification

Run from the repository root:

```sh
pnpm --filter @edgewarden/web run check
pnpm --filter @edgewarden/web run test
pnpm build
```

The web suite checks matching keys and placeholders, nonempty translations,
English catalog content, and untranslated Chinese in production source. The
source guard allows only the language's own name and bilingual search tokens;
it ignores comments, test data, and generated code. It is not a substitute for
reviewing new hard-coded English copy.

Component tests exercise real forms and vault controls in both languages,
including switching without losing a draft or modifying stored credentials.
Before release, also inspect narrow layouts, dialogs, and validation errors in
English and Chinese. Longer labels must remain readable without changing the
design system's component styles.
